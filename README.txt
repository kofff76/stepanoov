1. Replace the demo artist name “Adrian Valente” and voice type in index.html.
2. Replace hero.png and portrait-01…06.png with the client photos using the same filenames.
3. Replace schedule, repertoire, press quotes and management contacts in index.html.
4. Replace opera-house photos/logos in assets/images/ or edit the theatre cards.
5. Connect the Featured Performance play button to Vimeo/YouTube only after the client supplies the video URL.
